# 안전한 빌드와 검증 산출물

웹과 데스크톱 프로덕션 빌드는 검증한 소스·정적 파일·런타임 의존성을 비공개 스테이징 폴더에 복사해 번들을 생성합니다. 배포 도구는 입력·출력 파일과 상위 폴더의 심볼릭 링크·정션·특수 파일을 거부합니다. 데스크톱 패키지는 검증된 소스와 운영 의존성을 새 비공개 임시 디렉터리로 복사한 다음 생성합니다. 설치 결과는 완성된 디렉터리 단위로 게시하고 체크섬은 임시 파일에서 원자적으로 교체합니다.

브라우저·데스크톱 테스트도 새 임시 디렉터리에 기록한 다음 종료 시 기존 output 경로로 결과를 게시합니다. 기존 결과 경로에 연결 파일이 있으면 다른 위치에 기록하지 않고 실패합니다. 빌드는 해당 사용자가 소유한 깨끗한 작업 공간에서 실행하세요. POSIX에서는 다른 사용자가 쓸 수 있는 산출물 부모 폴더도 거부합니다. Windows 빌드 계정은 다른 로컬 계정에 작업 공간 및 상위 폴더의 수정 권한을 부여하지 않는 ACL이 있는 폴더에서 실행합니다.

이 검증은 다른 사용자가 심어 둔 경로를 따라 비밀 파일을 포함하거나 외부 파일을 덮어쓰는 일을 막기 위한 것입니다. 검증되지 않은 소스 코드나 npm 실행 스크립트 자체를 격리하는 도구는 아닙니다.

## Windows 공개 후보

`npm run package:desktop`은 개발 및 CI용 설치 파일을 만듭니다. CI는 npm 수명주기 스크립트를 일괄 실행하지 않고 잠긴 Electron과 Playwright 패키지의 전용 설치 도구만 호출합니다. 독립 실행 검사에서 원본 실행 파일의 Electron Fuses와 앱 시작을 검증하고, 네이티브 대화상자 자동화는 임시 복사본에서만 Node 검사 기능을 켜서 수행합니다.

공개 후보는 승인된 Windows 환경에서 신뢰할 수 있는 Authenticode 서명 자격 증명 또는 조직 서명 공급자를 electron-builder에 구성한 뒤 `ENGINE_SIGNER_THUMBPRINT`에 기대하는 서명 인증서의 40자리 16진수 지문을 설정하고 `npm run package:release`를 실행합니다. 설치 프로그램 및 앱 실행 파일에 대해 Windows가 유효하다고 판단하고 지정 지문과 일치하는 서명을 확인한 뒤에만 산출물을 내보냅니다. GitHub의 일반 브랜치 및 PR 검증에는 서명 자격 증명이 필요하지 않습니다. SHA-256은 배포 파일의 무결성 확인에 사용합니다.
