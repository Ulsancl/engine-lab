# Engine Lab 계산 모형

Engine Lab은 대표 직렬 4기통 DOHC 엔진의 기구 운동과 4행정 순서를 관찰하는 모형이다. 회전수는 사용자가 지정하는 입력이다. 연소가 만들어 낸 토크·출력·연비·온도·압력 또는 실제 차량 성능을 계산하지 않는다.

저장 모형 식별자는 `engine-kinematics-1`이다.

## 단위와 좌표

길이는 m, 각도는 rad, 시간은 s를 사용한다. 화면의 mm·도 단위는 표시 변환이다. +Y는 위, +Z는 크랭크·캠 축, +X는 좌우 방향이다. 크랭크 중심은 원점이고 실린더 중심의 Z는 `(i − 1.5) × 0.104`이며 i는 0부터 3이다.

| 대표 치수 | 값 |
|---|---:|
| 보어 / 행정 | 0.086 / 0.086 m |
| 커넥팅로드 중심 거리 | 0.143 m |
| 실린더 간격 | 0.104 m |
| 피스톤 핀에서 크라운까지 | 0.026 m |
| 블록 데크 높이 | 0.214 m |
| 밸브 시트 높이 / 좌우 위치 | 0.225 / ±0.020 m |
| 밸브 기울기 | 20° |
| 같은 종류의 밸브 쌍 Z 간격 기준 | 실린더 중심에서 ±0.018 m |
| 캠 기본 반지름 / 최대 리프트 | 0.030 / 0.006 m |
| 시트에서 캠까지 대표 거리 | 0.064 m |
| 팔로워 대표 반지름 | 0.011 m |

모든 치수와 타이밍은 자체 교육용 설정이다. 특정 제조사의 엔진 사양이나 설계 도면을 재현하지 않는다.

단기통 보기는 이 직렬 4기통에서 선택한 한 실린더를 확대하는 기능이다. 별도의 단기통 엔진이나 그 진동·균형 특성을 계산하는 모드가 아니다. 원리 확인에 사용한 자료와 자체 설정의 구분은 [참고 자료](references.md)에 정리했다.

## 크랭크·피스톤·로드

실린더별 위상 θ=0은 압축 끝 상사점이며 팽창 행정의 시작이다. 크랭크 반경 `r = 행정/2`, 로드 길이 `L = 0.143`일 때:

```text
크랭크 핀 = (r sinθ, r cosθ, z)
피스톤 핀 = (0, r cosθ + √(L² − r² sin²θ), z)
로드 각도 β = atan2(r sinθ, √(L² − r² sin²θ))
```

로드는 크랭크 핀에서 +Y 방향으로 만든 형상에 표준 `Rz(+β)`를 적용하면 피스톤 핀에 연결된다. 크랭크 형상의 회전은 `Rz(−θ)`이다. 두 핀 사이 거리는 모든 위상에서 L이며, 피스톤 핀 높이는 상사점 0.186 m, 하사점 0.100 m이다. 유한한 로드 길이를 사용하므로 단순 사인파 피스톤 운동과 다르다.

피스톤 위치는 360°마다 반복한다. 밸브·행정은 720°마다 반복한다. 1·4번과 2·3번은 각각 같은 피스톤 높이지만 서로 다른 행정에 있다.

## 행정과 점화 순서

전역 크랭크각을 Θ라 할 때 실린더 위상은 `wrap720(Θ − 점화 기준 위상)`이다. 1·2·3·4번의 점화 기준 위상은 각각 0°, 540°, 180°, 360°다. 따라서 180°마다 1 → 3 → 4 → 2 순서로 팽창을 시작한다.

| 실린더 위상 | 행정 |
|---|---|
| 0° 이상 180° 미만 | 팽창(power) |
| 180° 이상 360° 미만 | 배기(exhaust) |
| 360° 이상 540° 미만 | 흡기(intake) |
| 540° 이상 720° 미만 | 압축(compression) |

이는 기구의 상태 구분이다. 불꽃·연소 색 또는 유로 화살표를 표시하더라도 측정 압력·온도·유량을 뜻하지 않는다. 밸브의 조기 열림·늦은 닫힘과 행정 구분은 서로 다른 값으로 유지한다.

여기의 ‘점화 기준 위상’은 팽창 시작을 배치하기 위한 기준이다. 실제 점화 진각이나 연소 지속시간을 모델링한 값은 아니다. 화면의 0–720°는 1번 실린더 기준의 전역각이며, 선택 실린더의 행정 버튼은 해당 실린더의 위상으로 이동한다. 예를 들어 3번의 팽창 0°로 이동하면 전역각은 180°다.

## 밸브 리프트와 캠

기본 흡기 이벤트는 350–580°, 배기는 140–370°다. 두 이벤트의 지속시간은 각각 230°이며 350–370° 구간은 밸브 오버랩이다. 열린 구간의 각도를 u=`π(θ−열림각)/(닫힘각−열림각)`로 두면 리프트는 `0.006 sin²u`이다. 구간 밖과 양 끝점은 리프트 0, 크랭크각에 대한 1차 미분 0이다. 끝점의 2차 미분은 안쪽·바깥쪽 값이 다르므로 C2 연속 프로파일이라고 주장하지 않는다.

위상 이동·주기 환산에서 생기는 부동소수점 오차로 끝점이 극미소 열림으로 표시되지 않도록 약 2.3×10⁻¹⁴ rad 이내의 끝점 오차는 닫힌 상태로 처리한다.

흡기 위상 조절은 ±10° **크랭크각**이다. 양수는 흡기 이벤트를 앞당기며 `기본 리프트(θ + 조절각)`으로 계산한다. 최대 리프트와 지속시간은 유지되고 배기 이벤트는 바뀌지 않는다.

| 흡기 조절 | 흡기 열림–닫힘 | 두 밸브가 함께 열린 구간 | 오버랩 길이 |
|---|---|---|---:|
| −10° 지각 | 360–590° | 360° 초과 370° 미만 | 10° |
| 0° 기본 | 350–580° | 350° 초과 370° 미만 | 20° |
| +10° 진각 | 340–570° | 340° 초과 370° 미만 | 30° |

표의 열림·닫힘 순간 자체에서는 리프트가 정확히 0이다. 기본 설정은 흡기 상사점 10° 전 열림·흡기 하사점 40° 후 닫힘, 배기 하사점 40° 전 열림·배기 상사점 10° 후 닫힘이다. 진각으로 오버랩이 커지는 것은 이 고정 배기 설정에서의 기하학적 결과다. 출력·연비가 좋아진다는 뜻이 아니며 회전수·부하에 따른 최적 타이밍을 추천하지 않는다.

캠각은 배기 `Θ/2`, 흡기 `Θ/2 + 흡기 조절각/2`다. 따라서 크랭크 720° 동안 캠은 360° 회전한다. 캠 프로파일 자체에는 위상 조절을 다시 넣지 않는다.

`valveTiming(settings)`는 선택 실린더 기준의 `{ intake: { open, close }, exhaust: { open, close }, overlapRad }`를 크랭크 라디안으로 반환한다. 수치 안내와 그래프 경계는 이 값을 사용하며, 곡선 높이는 같은 설정의 `valveLift`로 계산한다. 반환 객체를 바꾸어도 내부 타이밍 상수는 바뀌지 않는다.

캠의 기본 지지함수는 캠 프로파일각 φ에 대해 다음과 같다. L, L′, L″은 위의 기본 리프트와 **크랭크각**에 대한 미분이다.

```text
h(φ)   = 0.030 + L(wrap720(2φ))
h′(φ)  = 2 L′(wrap720(2φ))
h″(φ)  = 4 L″(wrap720(2φ))
프로파일 점 p = h n + h′ t
```

여기서 n=(cosφ,sinφ), t=(−sinφ,cosφ)이다. `h+h″`의 최소값은 약 0.006601 m로 양수이므로 이 교육용 프로파일의 지지곡선은 볼록하다. 장면은 팔로워 방향각 α에 대해 각 실린더 로브를 `Rz(α − 캠각 + 점화 기준 위상/2)`로 배치한다. 이 관계는 팔로워 방향에서 읽은 캠 리프트와 snapshot의 밸브 리프트가 일치하도록 한다. 실제 밸브 접촉·피스톤 간섭·분해 변환의 시각 검증은 장면 구현에서 별도로 수행한다.

## 시간과 수치 범위

허용 rpm은 100–6000이며 기본값은 1200이다. `dΘ/dt = 2π·rpm/60`으로 크랭크각을 진행한다. 화면 재생 배율은 UI에서 시간에 적용하며 계산 모형의 rpm 또는 기구비를 바꾸지 않는다.

| 관찰 방식 | 설정 rpm | 재생 배율 | 화면 크랭크 rpm | 720° 한 사이클 시간 |
|---|---:|---:|---:|---:|
| 기본 저속 관찰 | 1200 | 1/40 | 30 | 4 s |
| 실시간 선택 | 1200 | 1 | 1200 | 0.1 s |
| 한 사이클 천천히 보기 | 현재 설정 유지 | 15/설정 rpm | 15 | 8 s |

화면 rpm은 `설정 rpm × 배율`, 사이클 시간은 `120 / 화면 rpm`이다. 안내는 전역각 0°·1번 실린더에서 시작해 한 사이클 뒤 멈춘다. 8초는 화면이 보이는 동안 중단 없이 재생한 목표 시간이다. 창이 숨겨지면 관찰을 멈추며, 화면 프레임 지연에 따라 완료 표시 시점은 조금 늦어질 수 있다. 고속 재생에서는 샘플링 때문에 역회전처럼 보이거나 짧은 불빛을 놓칠 수 있으므로 위치 확인은 일시정지·각도 이동·저속 재생으로 한다.

누적 상태는 항상 0 이상 4π 미만의 주기 각도다. 큰 유한 시간도 먼저 한 사이클 시간의 나머지로 줄여 곱셈 오버플로를 피한다. 음수·비유한 시간은 진행하지 않는다. 잘못된 회전수·위상 입력은 기본값, 유한 범위 밖 값은 허용 범위로 제한한다. 문자열을 숫자로 묵시 변환하지 않는다.

극미소 음수에 한 주기를 더한 결과가 부동소수점 반올림으로 정확히 4π가 되면 같은 주기 위치인 0으로 정규화한다. −0도 0으로 정규화한다. 실험 파일 읽기는 별도의 엄격한 검증을 사용하여 손상·범위 초과 파일을 이런 기본값 처리로 조용히 바꾸지 않는다.

이 API는 총 회전수·총 점화 횟수를 반환하지 않는다. 한 프레임에서 여러 사이클을 진행했을 때 이벤트 횟수가 필요하면 UI 또는 별도 이벤트 누적기가 통과한 경계를 계산해야 한다. 이미 정밀도를 잃은 거대한 누적 각도에서 과거 위상을 복원할 수는 없으므로 정상 재생은 `advanceAngle`의 제한된 각도를 계속 사용한다.

## 검증 범위

독립 거리식으로 로드 길이·크랭크 반경·회전된 로드 양 끝 연결을 검증한다. 알려진 상·하사점, 1-3-4-2 순서, 피스톤의 360° 주기와 행정의 720° 주기, 밸브 이벤트·미분·오버랩·위상 이동, 캠 지지함수의 수치 미분·볼록성·실린더별 접촉 관계, 시간 분할 일치와 장시간 유한 범위를 검사한다.

윤활의 압력·유막·마찰·마모, 밸브 바운스·스프링 서지, 변형, 가스 교환·연소·열전달·노킹은 계산 범위 밖이다. 이 문서의 기구 검증은 실제 엔진 설계·정비·안전 승인이나 성능 보증을 제공하지 않는다.
