# Engine Lab 상세 관찰 개선

확인일: 2026-10-02. 기존 직렬 4기통 DOHC의 정확한 기구 운동을 부품별로 관찰할 수 있게 한다. 저장 모형 식별자 `engine-kinematics-1`, 기존 위치·밸브 리프트·시간 진행은 유지한다. 연소나 새로운 힘 모형을 추가하지 않는다.

## 새 관측값

| 부품 | 관측값 | 해석 범위 |
| --- | --- | --- |
| 피스톤·링·핀 | 상사점 이동량, 순간 속도·가속도, 평균 피스톤 속력, 상사점 기준 쓸린 체적 | 링 마찰·핀 하중·연소 압력 미해석 |
| 커넥팅 로드 | 기울기, 각속도·각가속도, 중심 거리와 길이 비 | 강체 기구 운동. 질량·관성력·베어링 하중 미해석 |

공통 치수는 `GEOMETRY`를 사용한다. `engineDetail`은 SI 숫자 관측값을 반환하고, `describeEngineDetail`은 부품별 최대 6개 표시 행과 해석 문구를 만든다. 실린더가 명시된 부품은 해당 번호를 우선한다. 공통 부품은 현재 선택된 실린더의 값을 보여 준다. 상세값을 생성하는 동안 원본 snapshot과 설정을 수정하지 않는다.

## 읽을 때 구분할 점

- 속도·가속도·밸브 열림 시간은 설정한 실제 rpm 기준이다. 화면을 천천히 재생하거나 일시정지해도 값은 그 각도에서의 기구 운동을 나타낸다. rpm을 두 배로 하면 속도는 두 배, 가속도는 네 배가 된다.
- 피스톤 속도와 가속도는 위쪽이 양수다. 상사점 이동량은 아래로 내려온 거리이므로 그 변화 방향과 부호가 반대다. 로드 각도·각속도는 +Z 기준, 밸브 속도는 열림이 양수다.
- 밸브의 열림·닫힘 경계에는 하나의 가속도 값을 부여하지 않는다. 속도까지 연속인 대표 리프트지만 가속도는 불연속이므로, ‘끝점에서 불연속’으로 읽는다.
- 86 mm 보어·86 mm 행정의 네 실린더 총 배기량은 약 1.998 L다. 상사점 기준 쓸린 체적은 연소실 총체적이 아니다. 가스 압력·압축비·흡배기 유량을 추정하는 값으로 사용하지 않는다.
- 기구의 가속도에서 힘·토크·출력을 만들어 내지 않는다. 윤활 입자와 불꽃도 계산된 유량·연소 상태를 뜻하지 않는다.

## 검증

새 수치 검증은 `tests/detail-model.test.mjs`에 있다. 위치 표본의 독립적인 5점 수치 미분, 알려진 상·하사점과 로드 극값, 속도 적분으로 복원한 행정·평균 속력·밸브 이동 거리, rpm 배수 관계, 선택 실린더와 진각, C1 끝점, 모든 부품 표시값의 비변경성을 검사한다. 상세한 수식·단위·경계 관례는 [계산 모형](model.md)에 기록했다.
