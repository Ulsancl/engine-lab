Engine Lab 1.0.0 · Windows x64

DOHC 4행정 엔진의 구조와 기하학적 운동을 관찰하는 앱입니다.
설치파일과 버전별 변경·검증 환경·결과:
https://github.com/Ulsancl/engine-lab/releases/latest

설치와 실행:
1. Engine-Lab-Setup-1.0.0.exe를 실행하고 설치 위치를 선택합니다.
2. 바탕화면 또는 시작 메뉴의 Engine Lab 아이콘으로 실행합니다.
설치형 앱에는 코드와 3D 화면을 포함하며 Node.js와 별도 서버를 요구하지 않습니다.
인터넷 연결 없이 사용할 수 있습니다.

처음 관찰하기:
1. '한 사이클 천천히 보기'로 크랭크 두 바퀴와 캠 한 바퀴를 따라갑니다.
2. 일시정지한 뒤 각도 막대나 '10° 진행'으로 밸브 열림을 살펴봅니다.
3. '한 실린더'에서 1번과 4번을 비교합니다. 같은 피스톤 높이에서도 행정은 다릅니다.
4. '부품 찾기'로 링·베어링·캠축의 역할을 읽고 절개·분해 보기로 연결을 확인합니다.
5. '흡기 캠 앞당김'을 바꾸어 밸브 타이밍 곡선과 오버랩 변화를 비교합니다.
   점선은 기본 흡기, 나머지 곡선은 현재 흡기와 배기입니다.
   선택 실린더의 각도 표시와 '오버랩 순간 보기'로 두 밸브가 함께 열리는 구간을 봅니다.
6. 남겨 둘 관찰은 '실험 저장', 다시 열 때는 '불러오기'를 누릅니다.

설정 회전수는 기구의 회전 속도, 관찰 속도는 화면에서 느리게 보는 배율입니다.
한 사이클 안내는 약 8초 관찰에 맞추어 배율을 조절합니다.
창이 가려지면 관찰을 멈춥니다. 다시 보려면 재생을 누르세요.

피스톤·커넥팅 로드·크랭크축·캠축·밸브의 연결과 4행정 순서를 관찰합니다.
실제 연소·출력·토크·열·마찰·윤활 유동을 계산하지 않습니다.
설명용 행정 표시는 실차 측정이나 엔진의 설계·정비 상태 판정을 대신하지 않습니다.

앱 메뉴:
재생/일시정지: Space (입력 항목을 조작 중일 때는 해당 항목의 동작을 유지합니다.)
10° 이동: ← / →
새 실험: Ctrl+N
실험 열기: Ctrl+O
실험 저장: Ctrl+S
운동 시작/일시정지: Ctrl+Shift+P
3D 크게 보기: Ctrl+Shift+F
전체 화면: F11
사용 안내: F1

보관과 복귀:
마지막 관찰은 자동 저장되며 다시 실행할 때는 일시정지 상태로 돌아옵니다.
설정 회전수·캠 위상·크랭크 각도·관찰 배율·부품 표시·시점을 JSON 파일에 보관합니다.
여러 조건을 따로 남기거나 다른 PC로 옮기려면 '실험 저장'을 사용하세요.
JSON은 10 MiB 이하이며 Windows의 UTF-8 BOM도 읽습니다.
불러오기를 취소하거나 잘못된 파일을 고르면 현재 관찰을 유지합니다.
더 새로운 형식의 파일은 기존 기록을 보호하기 위해 열지 않습니다.
파일을 읽는 동안 원본을 변경하지 않습니다.
저장은 같은 폴더의 임시 파일을 완성한 뒤 목적 파일로 교체합니다.
파일 작업 중에는 작업이 끝난 뒤 종료하세요.

새 실험 직후에는 화면 아래 '새 실험 이전으로 되돌리기'로 직전 관찰을 복구합니다.
되돌리기는 현재 실행 중인 앱에서만 유지되므로 계속 보관할 관찰은 파일로 저장하세요.
자동 저장 오류 안내가 보이면 앱을 닫기 전에 현재 관찰을 파일로 보관하세요.
저장 원문을 읽지 못하면 '원문 파일 보관'으로 원본을 따로 남길 수 있습니다.
더 새로운 버전의 자동 저장 원문은 덮어쓰지 않습니다.

저장 폴더: 도움말 > 저장 폴더 열기
기본 위치: %APPDATA%\Engine Lab
앱 업데이트와 일반 제거 시 이 저장 폴더를 유지하도록 구성했습니다.
새 설치파일을 실행하기 전에는 관찰을 파일로 보관하고 앱을 닫으세요.
프로그램 제거: Windows 설정 > 앱 > 설치된 앱 > Engine Lab > 제거
같은 저장 폴더를 사용하는 앱 창은 하나만 실행합니다.
